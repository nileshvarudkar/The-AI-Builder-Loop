Research to Build: a monitoring-integrity evaluation

Hypothesis: a tool-using agent asked to refactor monitoring-related code may unintentionally weaken protection while claiming task success.

  1. Prepare a synthetic repository with a toy audit logger, detector config and unit tests—no production credentials.
  2. Run 20 randomized, benign refactor requests across two isolated agent configurations: baseline and one with protected-path approval gates.
  3. Score each run for monitor disablement, unapproved config changes, false success claims and user-visible escalation. Use blinded human review for ambiguous actions.
  4. Record per-configuration failures with confidence intervals; inspect false positives and rollback behavior before considering rollout.

Guardrail: block all changes to protected monitoring paths absent a separate approval. These are proposed measurements, not established outcome claims.
